# Welfare Flow - Quick Reference Guide

**One-Page Overview for All Roles**

---

## 🏠 MEMBER (Regular User)

### Navigation
```
HOME > PROFILE > CONTRIBUTIONS > BENEFICIARIES > NEWS > CHAT > DOCUMENTS
```

### What You See
- **Dashboard**: Your contribution status + quick actions
- **Contributions**: All payments you've made
- **Outstanding**: Amount you still owe
- **Penalties**: Any fines owed

### Quick Actions
| Action | How | Result |
|--------|-----|--------|
| **Pay** | Click "Pay Now" | M-Pesa prompt appears |
| **View Status** | Go to Contributions | See all payments |
| **Download Receipt** | Click receipt icon | PDF downloads |
| **Update Profile** | Edit in Profile tab | Changes saved |

### Key Info
- Total Collected: All payments made
- Expected: Monthly amount needed
- Outstanding: What you owe
- Penalties: Late payment fees

## 🔄 COMMON WORKFLOWS AT A GLANCE

### Workflow 1: Member Pays Contribution
```
1. Member logs in
2. Views dashboard (sees "Outstanding: KES 500")
3. Clicks "Pay Now"
4. Enters amount & phone
5. M-Pesa prompt on phone
6. Enters PIN
7. Payment confirmed
8. Dashboard updates (status: "Paid")
9. Receipt generated
```

### Workflow 2: Fund Withdrawal Request
```
1. Treasurer creates withdrawal request
2. Shows amount, reason, recipient
3. Sent to: Chairperson + Secretary + Treasurer
4. Each reviews and digitally signs
5. Final signature completes
6. M-Pesa payout initiated
7. Member receives funds
8. Receipt generated for records
```

### Workflow 3: Meeting Minutes
```
1. Secretary creates new meeting
2. Enters date, attendees, agenda
3. Documents discussions
4. Uploads supporting files
5. Submits for approval
6. Chairperson reviews
7. Approves or requests changes
8. Approved = Archived + Available to view
```

### Workflow 4: Bank Reconciliation
```
1. Treasurer gets bank statement
2. Saves as CSV/Excel
3. Uploads to system
4. System auto-matches to payments
5. Reviews unmatched items
6. Marks as confirmed
7. Report generated
8. Saved for audit
```
